Registration state is inferred offline from the aircraft's ICAO 24-bit address
allocation. This is not the departure airport, operator nationality, or current
position. Incorrect/spoofed addresses can give an incorrect state; non-ICAO,
unallocated and special-use addresses display Unknown. No new API requests.

Data: ICAO Annex 10 Volume III, Table 9-1, Amendment 92, transcribed by
ibosoftnet/icao-aircraft-addresses under CC0-1.0.
